Política de Privacidade

Última atualização: 14/11/2026.

1. Quais dados são usados

O aplicativo usa somente o que o TikTok fornece após a autorização do criador: identificação básica da conta (nome de exibição e nome de usuário) e o token de acesso necessário para publicar vídeos.

2. Para que são usados

Os dados servem exclusivamente para publicar os vídeos do próprio criador na conta conectada. Não são usados para publicidade, perfilamento nem nenhuma outra finalidade.

3. Onde ficam guardados

O token de acesso fica guardado no computador do criador, em uma pasta de segredos que não é enviada a ninguém. Não há banco de dados de usuários nem serviço de terceiros que receba esses dados, além do próprio TikTok e da plataforma usada para hospedar o vídeo para a publicação.

4. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros.

5. Retenção e exclusão

O token pode ser apagado a qualquer momento pelo criador, e a conexão pode ser removida nas configurações do TikTok. Após a remoção, o aplicativo não acessa mais a conta.

6. Seus direitos

O criador pode revogar o acesso, pedir a exclusão dos dados guardados e tirar dúvidas pelo canal do YouTube Memory Cláudio.

7. Alterações

Esta política pode ser atualizada. A data no topo indica a última versão.
